# Poodman 1

## Python programming

![Book image](../images/p007-01.png)

Python is one of the widely used high-level programming languages. Because it is easy to learn and powerful for implementing programs, it is used in many areas of information technology. Learning this language gives students a solid start for entering the world of programming and solving computer problems.

In this poodman, students learn the basics of programming in Python and gain the skills needed to model data and organize programs. Learning unit 1 is about “data modeling,” where you learn about data types, variables, and data structures, and how to store and process information appropriately in programs. In learning unit 2, “Working with functions and modules,” students learn how to define and use functions, and how to split a program into smaller parts and use modules to produce code that is organized, readable, and easy to extend.
