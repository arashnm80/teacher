Python is a high-level, widely used programming language. Because it is easy to learn and powerful for building programs, it is used in many areas of information technology. Learning this language gives students a good way into the world of programming and solving computer problems.

In this module, students learn the basic concepts of programming in Python and gain the skills needed for **data modeling** and **organizing programs**. The first learning unit is about «data modeling»: the student gets to know data types, variables, and data structures, and learns how to store and process information in programs properly. In the second learning unit, «working with functions and modules», students learn how to define and use functions, and how to write organized, readable, and extensible code by dividing a program into smaller parts and using modules.
