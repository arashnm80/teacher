## Media queries (Media query)

A media query is a CSS technique that lets you set the properties of elements based on the features of different devices (such as screen size, resolution, orientation, and so on). It lets developers optimize their websites and web apps for all kinds of devices (such as phones, tablets, and desktops).

Media queries are written in CSS with the @media rule and have the structure below:

```
@media media-type and (condition) {
       CSS rules
}
```
