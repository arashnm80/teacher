# کتاب طراح سایت — پایه یازدهم

متن کتاب درسی «طراح سایت» (رشته شبکه و نرم‌افزار رایانه، پایه یازدهم) که با `convert_book.py` از PDF به مارک‌داون تبدیل شده است.

- منبع: `original-reference/11th-grade-programming-book.pdf` (۳۳۶ صفحه)
- تصویرها: ۶۱۱ فایل در `images/`
- شماره صفحهٔ چاپی کتاب به‌صورت `<!-- page N -->` بالای هر صفحه آمده است.
- قاب‌های کتاب (نکته، فعالیت، کنجکاوی و ...) به‌صورت نقل‌قولی آمده‌اند که سطر اول آن نام قاب است.
- هر شکل یک تصویر کامل از همان ناحیهٔ صفحه است و زیرنویس «شکل N» زیر آن آمده است.
