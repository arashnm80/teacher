# طراح سایت — نسخه‌ی کامل آفلاین

این فایل فشرده کل سایت است: درس‌ها و زمین بازی. یک بار دانلود کنید؛ بعد از آن اینترنت لازم نیست.

- درس‌ها: فایل `index.html` را با دوبار کلیک باز کنید.
- زمین بازی: فایل `شروع.bat` را با دوبار کلیک اجرا کنید (Python 3 با tkinter لازم است). پیشرفت شما در همین نشانی محلی ذخیره می‌ماند؛ همیشه با همین فایل باز کنید.
- ورود و ثبت‌نام: داخل زمین بازی می‌توانید مثل سایت وارد شوید. هر وقت اینترنت دارید، نتیجه‌های شما به معلم ارسال می‌شود. کنار هر مسئله‌ی حل‌شده می‌بینید که به معلم رسیده (✓) یا هنوز منتظر ارسال است (●). آموزش مسئله‌ها بعد از اولین ورود (با اینترنت) روی همین دستگاه ذخیره می‌شود.
- مهلت‌ها: یک نتیجه وقتی برای نمره حساب می‌شود که قبل از مهلت به معلم برسد؛ پس مسئله‌ی حل‌شده را قبل از مهلت ارسال کنید.
- به‌روزرسانی: وقتی سایت تغییر کند، در بالای زمین بازی اعلانی می‌بینید و با یک کلیک همین نسخه به‌روز می‌شود (فقط فایل‌های تغییرکرده دانلود می‌شوند و پیشرفت شما دست نمی‌خورد).

# Site Design — full offline copy

One zip holds the whole site: lessons and playground. Download once; after that no internet is needed.

- Lessons: double-click `index.html`.
- Playground: double-click `شروع.bat` (needs Python 3 with tkinter). Progress is kept at the same local address, so always start it the same way.
- Sign in and sign up inside the playground, as on the website. Whenever you have internet, your results are sent to the teacher. Next to each solved problem you see whether it has reached the teacher (✓) or is still waiting to be sent (●). The tutorials are saved on this device after the first sign-in (with internet).
- Deadlines: a result counts for the score when it reaches the teacher before the deadline, so send solved problems before it.
- Updates: when the website changes, a notice appears at the top of the playground; one click updates this copy (only changed files are downloaded, and your progress is not touched).
