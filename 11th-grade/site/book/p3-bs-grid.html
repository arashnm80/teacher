پودمان ۳: صفحات وب تعاملی

شبکه Grid

صفحه ۱۶۰

شبکه‌بندی صفحه (Grid Systems)

بوت‌استرپ دارای یک سیستم شبکه‌بندی با نام Grid است که توسط Flexbox ایجاد شده است و امکان تقسیم پهنای صفحه را به 12ستون فراهم می‌کند. هر سلول در این شبکه می‌تواند محتوای بخشی از صفحه را درون خود نگه دارد. سیستم Grid امکان گروه‌بندی ستون‌ها را برای ایجاد ستون‌های عریض‌تر فراهم می‌کند به‌طوری‌که فضای کافی برای قرار دادن محتوا درون یک ستون موجود باشد. سیستم Grid واکنش‌گرا است و بسته به اندازه صفحه، ستون‌ها را به‌طور خودکار مرتب می‌کند.

استفاده از کلاس‌های شبکه‌بندی (rows و columns)

برای ایجاد سطرها و ستون‌های شبکه از کلاس‌های row و col استفاده می‌شود. کلاس row باعث می‌شود سلول‌های شبکه در یک خط افقی قرار بگیرند و فواصل مناسب بین آنها اعمال شود. پهنای ستون‌ها به‌صورت خودکار توسط پارامتر size در نام کلاس col مشخص می‌شود. شکل کلی کلاس col به صورت col-breakpoint-size است، پارامتر breakpoint به اندازه دستگاه (sm, md, lg,xl, xxl) و پارامتر سایز به اندازه ستون اشاره دارد. به‌عنوان مثال col-sm-3 یعنی اشغال سه ستون از 12 ستون در تمام دستگاه‌های بزرگ‌تر یا مساوی 576 پیکسل.

شبکه سطرها و ستون‌ها باید درون یک عنصر نگهدارنده قرارگیرد. بوت‌استرپ دارای دو کلاس با اسامی container و container-fluid است که برای ایجاد نگهدارنده استفاده می‌شوند. تفاوت این دو نگهدارنده در میزان حاشیه چپ و راست آنهاست. کلاس container یک فضای خالی با پهنای مساوی در چپ و راست عنصر نگهدارنده ایجاد می‌کند، در حالی‌که کلاس container-fluid تمام پهنای صفحه را اشغال می‌کند.

واکنش‌گرایی و کلاس‌های مرتبط

واکنش‌گرایی به‌معنای توانایی یک صفحه وب برای تغییر و سازگاری با اندازه‌ها و ویژگی‌های مختلف دستگاه‌ها و صفحه نمایش‌ها است. در یک طراحی واکنش‌گرا عناصر وب‌سایت به‌طور خودکار اندازه و چیدمان خود را تغییر می‌دهند تا مناسب با اندازۀ صفحه نمایش کاربر باشند. هدف از انجام یک طراحی واکنش‌گرا (Responsive) این است که تجربه کاربری بهتری برای بازدیدکنندگان فراهم شود. برای طراحی عناصر واکنش‌گرا، روش‌های مختلفی به شرح زیر موجود است:

  1. Media query : برای تنظیم ویژگی‌های عناصر در دستگاه‌های مختلف

  2. Flexbox : برای مدیریت نحوه چینش عناصر و فضای بین آنها

  3. CSS Grid : برای سازمان‌دهی عناصر در سطرها و ستون‌ها

  4. استفاده از max-width به جای width برای اینکه تصاویر در اندازه‌های مختلف به‌درستی نمایش داده شوند:

  1. استفاده از واحدهای نسبی %، rem و em به‌جای استفاده از واحدهای ثابت (مانند px)

  2. به‌کارگیری فریم‌ورک‌هایی مانند بوت‌استرپ که دارای کلاس‌های واکنش‌گرای آماده هستند.

Grid Systems

Bootstrap has a grid system named Grid, built with Flexbox, that divides the page width into 12 columns. Each cell of this grid can hold the content of part of the page. The Grid system lets you group columns into wider columns, so there is enough room for content in one column. The Grid system is responsive and rearranges the columns automatically depending on the page size.

Using the grid classes (rows and columns)

The row and col classes are used to create the rows and columns of the grid. The row class puts the grid cells on one horizontal line with suitable spacing between them. The width of the columns is set by the size parameter in the col class name. The general form of the col class is col-breakpoint-size, where breakpoint is the device size (sm, md, lg, xl, xxl) and size is the column size. For example, col-sm-3 means taking three of the 12 columns on all devices 576 pixels or wider.

The grid of rows and columns must be inside a container element. Bootstrap has two classes, container and container-fluid, for creating containers. They differ in their left and right margins: the container class leaves equal empty space on the left and right of the container, while container-fluid takes the full width of the page.

Responsiveness and the related classes

Responsiveness is a web page's ability to change and adapt to the sizes and features of different devices and screens. In a responsive design, the website's elements change their size and layout automatically to suit the user's screen. The goal of responsive (Responsive) design is a better experience for visitors. There are several ways to design responsive elements:

  1. Media query: to set the properties of elements on different devices

  2. Flexbox: to manage how elements are arranged and the space between them

  3. CSS Grid: to organize elements in rows and columns

  4. Using max-width instead of width so that images are shown correctly at different sizes:

  1. Using the relative units %, rem, and em instead of fixed units (such as px)

  2. Using frameworks such as Bootstrap that have ready-made responsive classes.
